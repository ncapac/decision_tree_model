# Documentation rules

- Keep stable platform contracts separate from per-round records.
- Write current truth, not a chronological dump. Put decisions and amendments in
  the owning round.
- Every claim about a measured result must link to a machine-readable artifact.
- Mark planned, pending, imported, reproduced, and measured statements distinctly.
- Do not copy old documentation wholesale; extract a fact only after classifying
  its authority and destination.
- Update `docs/README.md` when adding, superseding, or retiring a document.
